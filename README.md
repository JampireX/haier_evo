# Haier Evo integration
[![hacs_badge](https://img.shields.io/badge/HACS-Custom-orange.svg)](https://github.com/custom-components/hacs) [![stability-beta](https://img.shields.io/badge/stability-beta-33bbff.svg)](https://github.com/mkenney/software-guides/blob/master/STABILITY-BADGES.md#beta)

Неофициальная интеграция для работы [Haier Evo](https://haieronline.ru/evo-iot/) (RU, KZ, BY).

Бета-версия: может работать некорректно.

## Поддерживаемые устройства
Ниже приведен список типов устройств, работа с которыми была **проверена пользователями**:

- Кондиционеры
- Холодильники

В действительности интеграция должна поддерживать больше устройств. 
Если интеграция некорректно работает с вашим устройством или поддерживает не все функции - сообщите в [Issues](https://github.com/and7ey/haier_evo/issues) об этом. 

## Совместимость
Haier предлагает разные мобильные приложения для разных рынков и стран. Некоторые устройства совместимы с более чем одним приложением. Эта интеграция поддерживает только устройства, которыми можно управлять через приложение [Evo](https://haieronline.ru/evo-iot/). Загрузите приложение Evo и проверьте совместимость с вашим устройством.
Приложения из этого (неполного) списка на данный момент запрошены:

| Приложение      | Рынок         | Совместимость                           | Альтернатива                                                                    |
|-----------------|---------------|-----------------------------------------|---------------------------------------------------------------------------------|
| Haier Evo       | Россия        | :heavy_check_mark:                      |                                                                                 |
| Haier hOn       | Европа        | :x:                                     | [Andre0512/hon](https://github.com/Andre0512/hon)                               |

## Установка

### 1. Установка HACS (если не установлен)
Для работы интеграции требуется наличие HACS.
Инструкция для установки https://www.hacs.xyz/docs/use/download/download/

### 2. Добавление репозитория Haier Evo

Так как интеграция является кастомной, её необходимо добавить в HACS как пользовательский репозиторий:

1. Откройте **HACS** в боковой панели Home Assistant.
2. Нажмите на три точки (⋮) в верхнем правом углу и выберите **Custom repositories** (Пользовательские репозитории).
3. В поле **Repository** вставьте ссылку: `https://github.com/and7ey/haier_evo`
4. В поле **Category** выберите **Integration** (Интеграция).
5. Нажмите **Add** (Добавить).
6. Теперь найдите **Haier Evo** в поиске HACS и нажмите **Download** (Загрузить).

### 3. Настройка

1. Перезапустите Home Assistant.
2. Перейдите в **Настройки** > **Устройства и службы** > **Добавить интеграцию**.
3. Найдите в списке **Haier Evo** и введите данные вашего аккаунта от приложения Evo.

## Карточка кондиционера

Интеграция сама подключает карточку `custom:haier-evo-ac-card` — ресурс добавлять не нужно. Её можно выбрать в редакторе панели (основные настройки есть в визуальном редакторе, всё остальное — в YAML).

По умолчанию карточка минималистична: название и температура в комнате, кнопка питания, целевая температура, иконки режимов, одна строка компактных списков (вентилятор, жалюзи, пресет) и иконки функций устройства. Подписи значений берутся из переводов Home Assistant.

```yaml
type: custom:haier-evo-ac-card
entity: climate.kondicioner          # единственный обязательный параметр
```

Все параметры:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `name` | имя сущности | Своё название |
| `show_name`, `show_current`, `show_power` | `true` | Название, температура в комнате, кнопка питания |
| `show_labels` | `false` | Подписи под иконками и в списках (иначе — только подсказки) |
| `compact` | `false` | Уменьшенные отступы и кнопки |
| `hide_when_off` | `false` | `true` — у выключенного кондиционера оставить только заголовок и режимы; или список секций, которые скрывать |
| `sections` | `[temperature, modes, fan, swing, swing_horizontal, preset, switches]` | Какие секции показывать и в каком порядке; доступны ещё `selects` и `sensors` |
| `control_style` | `pills` | `pills` — компактные списки в одну строку, `chips` — ряд кнопок на каждый параметр |
| `modes`, `fan_modes`, `swing_modes`, `swing_horizontal_modes`, `preset_modes` | все доступные | Какие значения показывать и в каком порядке |
| `switches`, `selects`, `sensors` | всё с устройства | Явный список сущностей (можно чужие: `input_boolean`, `light`, …) |
| `exclude` | — | Сущности, которые не показывать |
| `temperature_step` | шаг сущности | Шаг кнопок −/+ |
| `debounce` | `700` | Через сколько мс после последнего нажатия −/+ отправить температуру (несколько нажатий — одна команда) |
| `labels` | — | Свои подписи: `{mode: {cool: Холод}, fan: {auto: Сам}}` |
| `icons` | — | Свои иконки по значению, секции или сущности: `{cool: mdi:snowflake-variant, fan: mdi:fan, switch.x: mdi:lamp}` |
| `colors` | цвета темы | Цвета режимов: `{cool: '#03a9f4'}` |
| `accent_color` | цвет темы | Цвет активных кнопок |
| `style` | — | Дополнительный CSS; размеры задаются переменными `--hac-btn`, `--hac-temp-size`, `--hac-gap`, `--hac-radius`, `--hac-accent` |

Пример:

```yaml
type: custom:haier-evo-ac-card
entity: climate.kondicioner
name: Спальня
compact: true
hide_when_off: true
sections: [temperature, modes, fan, swing, switches]
modes: [cool, heat, dry, auto]
exclude: [switch.kondicioner_sound]
labels:
  mode: {cool: Холод, heat: Тепло}
```
